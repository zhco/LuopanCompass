# 风水罗盘 (Luopan Compass)

一款专为地理先生设计的中国传统风水罗盘 Android 应用，支持授权激活机制。

## 功能特性

- **真实指南针** - 利用手机传感器实时显示朝向
- **二十四山盘** - 天盘与地盘双层二十四山显示
- **八卦方位** - 内圈八卦标识
- **坐山朝向** - 实时显示当前方位对应的山水
- **GPS定位** - 显示当前经纬度坐标
- **传统风格** - 仿古木纹金色罗盘设计
- **授权激活** - 一机一码授权机制，支持试用

## 二十四山

罗盘包含完整的二十四山方位：
- **四正**: 子(北)、卯(东)、午(南)、酉(西)
- **四隅**: 乾(西北)、艮(东北)、巽(东南)、坤(西南)
- **十二支**: 子丑寅卯辰巳午未申酉戌亥
- **八干**: 甲乙丙丁庚辛壬癸
- **四维**: 乾坤艮巽

## 授权激活说明

### 用户端

1. 首次打开应用，进入激活界面
2. 查看并复制"设备授权码"
3. 将设备授权码发送给管理员
4. 收到管理员回发的授权码后，输入并点击"立即激活"
5. 激活成功后可永久使用

### 免费试用

- 提供 **3 次免费试用** 机会
- 每次打开应用消耗 1 次试用
- 试用次数用完后必须激活

### 管理员端

管理员使用 `tools/license-generator.html` 工具生成授权码：

1. 用浏览器打开 `tools/license-generator.html`（完全离线运行，无需联网）
2. 将用户提供的设备授权码输入工具
3. 点击"生成授权码"
4. 将生成的授权码回发给用户

#### 批量授权

支持批量生成授权码，每行输入一个设备授权码，适合批量授权场景。

#### 授权算法

```
授权码 = MD5(设备ID + "luopan_fengshui_secret_salt_2026")
格式：取 MD5 前 16 位，每 4 位一组，XXXX-XXXX-XXXX-XXXX
```

## 技术栈

- Kotlin
- Android SDK 34
- 自定义 Canvas 绘制
- SensorManager (加速度计 + 磁力计)
- GPS LocationManager
- MD5 设备绑定授权

## 编译

```bash
# 使用 Gradle 编译
./gradlew assembleRelease

# APK 输出路径
# app/build/outputs/apk/release/app-release.apk
```

## GitHub Actions

本项目配置了 GitHub Actions 自动编译，每次推送代码到 main 分支时会自动：
1. 编译 Release APK
2. 上传 APK 到 Artifacts
3. 创建 GitHub Release

## 使用说明

1. 安装 APK 到 Android 手机
2. 授予位置权限
3. 激活应用（输入授权码或试用）
4. 将手机水平放置
5. 缓慢旋转手机校准罗盘
6. 罗盘会实时显示当前方位
